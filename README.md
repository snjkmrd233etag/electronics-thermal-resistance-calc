# CW ThermalCalc

Single-page React + Tailwind application for junction-to-ambient thermal resistance analysis in rugged defense electronics.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Notes

- No backend
- No external API calls
- Main application logic is contained in [pages/index.js](/C:/Users/etag4/OneDrive/Documents/GitHub/electronics-thermal-resistance-calc/pages/index.js)
- The app loads with the Conduction-Cooled VPX preset by default
